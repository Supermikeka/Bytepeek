# BytePeek · 字节透视

**纯 Python 零依赖的文件类型鉴定器** —— 不看后缀看字节，专治改名伪装、拼接马甲、灌水文件。

## ✨ 功能特性

- **58 种格式签名**：压缩包 / 图片 / 音视频 / 文档 / 字体 / 磁盘镜像 / 游戏资源……
- **结构走链验真**：命中魔数后按格式官方规则解析（MP4 box 链、ZIP 条目链、PNG chunk…），读得通才认领，杜绝"碰巧长得像"的误报
- **残缺 ZIP 抢救**：中央目录/结束记录被删的 ZIP 也能列出全部条目（本地头链遍历）
- **嵌套 / 拼接 / 马甲检测**：文件里藏压缩包、尾部接灌水数据、多种容器拼接，全部现形
- **熵分析**：未被识别的区域按信息熵分级（全零填充 / 高熵加密 / 中低熵未知）
- **伪装扩展名检测**：`.jpg` 其实是 EXE？一句话戳穿
- **纯文本智能识别**：HTML / JSON / XML / 脚本 / URL 快捷方式，无需魔数
- **快捷方式体检**：解析 LNK 指向，失效目标 / 指向可执行文件即时提醒
- **扫描历史**：SQLite 本地永久保存，随时重扫
- **HTML 报告导出**：一键生成完整诊断报告
- **零第三方依赖**：全部基于 Python 标准库

## 📦 使用

### 图形界面
运行 BytePeek.exe（单文件，免安装），点击选择文件即可扫描；结果区可查看字节构成图、发现明细与完整详情，并可一键导出 HTML 报告。

### 绑定右键菜单（首次使用推荐）

1. 打开 BytePeek
2. 在窗口上方勾选 **「绑定右键菜单」** —— 自动写入系统注册表
3. 之后任意文件右键 → **"用 BytePeek 扫描类型"**，右下角悬浮窗直接出结论

- 取消勾选即解除绑定
- **软件移动位置后**：重新打开软件会自动把右键指向新位置（也可重新勾选一次）
- 绑定写入的是当前用户注册表，**重启电脑后依然有效**

### 命令行
```
BytePeek.exe scan <文件路径>
```
输出完整 JSON 结果（segments / findings / warnings / coverage）。

## 🔨 从源码构建

```
pip install pyinstaller
pyinstaller --onefile --windowed --name BytePeek app.py
```

要求 Python 3.10+（Windows，tkinter 随附）。

## 🧠 工作原理（三层判定）

1. **签名搜索**：58 种魔数在文件中定位"可能是谁"
2. **结构验真**：14 种容器按自身规则走链解析，自洽才认领
3. **熵分类**：剩余区域按信息熵分级（全零填充 / 高熵加密 / 未知）

最后统一语境体检：灌水占比、多容器拼接、内嵌可执行文件、扩展名与内容不符……按红/黄/蓝三级给出警告。
